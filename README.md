# Store Sales Dashboard

## Overview

This project is a Power BI dashboard for analyzing store sales.

## Features

- Total Sales
- Total Profit
- Orders
- Monthly Trends
- Sales by Region
- Sales by Category
- Interactive Filters

## Tools Used

- Power BI
- Excel
- DAX
- Power Query
